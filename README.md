# 本地数字素材目录

管理数字素材的目录与标签信息。面向本地单机使用，采用 Python 3 标准库与 SQLite，无需安装第三方依赖。

当前实现三个操作：素材登记（`add`）、按标签精确查询（`query`）与导出完整目录（`export`）。使用过程中源文件保持只读，不扫描其他目录，也不解码素材内容。

## 用法

全局必填选项 `--db` 指定 SQLite 数据库文件；文件不存在时自动创建（不自动创建缺失的父目录）。

```sh
# 登记素材：一个文件路径、必填 --type、至少一个可重复的 --tag
python -m asset_catalog --db catalog.sqlite add demo.png --type image --tag demo

# 成功输出（退出码 0）：
# {"path": "/abs/path/demo.png", "type": "image", "tags": ["demo"]}

# 按完整标签查询（区分大小写，不做子串匹配）
python -m asset_catalog --db catalog.sqlite query --tag demo
# [{"path": "/abs/path/demo.png", "type": "image", "tags": ["demo"]}]
# 无结果时输出 []

# --tag 可重复传入：默认（--tag-mode all）素材需同时具备全部不同标签才入选；
# 重复条件等同于只传一次，条件顺序不影响结果，单个 --tag 时语义不变。
python -m asset_catalog --db catalog.sqlite query --tag demo --tag ui

# --tag-mode any：素材只要具备其中任一标签即入选，同样去重、按首次登记顺序各返回一次
python -m asset_catalog --db catalog.sqlite query --tag demo --tag ui --tag-mode any

# 查询时可选再按素材类型筛选：去除首尾空白后与登记类型完整匹配（区分大小写）
python -m asset_catalog --db catalog.sqlite query --tag demo --tag ui --type image
# --type 在标签命中范围内继续筛选；与 any 同用时素材既要命中任一标签，也要匹配该类型
# 不传 --type 时查询范围、输出与排序均与只按标签查询一致

# 导出完整目录：无筛选参数，标准输出仅为一个 JSON 数组
python -m asset_catalog --db catalog.sqlite export
# [{"path": "/abs/path/demo.png", "type": "image", "tags": ["demo"]}]
# 每条记录仅含 path、type、tags；按首次登记顺序各出现一次，空目录输出 []
```

## 规则

- 文件路径会解析为规范绝对路径（相对路径、`.`、`..` 及符号链接均会解析），同一规范路径重复登记将被拒绝。
- 目录数据库不能作为素材登记到自身：素材路径与 `--db` 数据库路径的规范绝对路径相同时拒绝登记（退出码 2，标准错误指出冲突的规范路径），数据库文件与既有记录保持不变；已有空文件不会因此被初始化，非 SQLite 或不兼容 SQLite 文件也保持原内容。路径不同的其他 SQLite 文件不受此限制，仍可正常登记。
- 类型与标签去除首尾空白后保存；标签按首次出现顺序去重，大小写保留。
- 查询结果按首次登记顺序排列；源文件事后被删除不影响已保存的记录。
- 查询 `--tag` 可重复传入，每个标签分别去除首尾空白，重复条件等同于只传一次，条件顺序不影响结果；默认（不传 `--tag-mode` 或传 `--tag-mode all`）素材需同时具备全部不同标签才入选，`--tag-mode any` 时只要具备其中任一标签即入选；命中多个条件的素材也只返回一次。`--tag-mode` 缺少值、为空、含首尾空白、大小写不符或不是 `all`、`any` 时按参数错误处理（退出码 2），该错误不创建数据库、不改动已有记录。
- 查询可通过 `--type` 在标签命中范围内再按类型完整匹配筛选；与 `--tag-mode any` 同用时，素材既要命中任一标签，也要匹配指定类型；非空类型无匹配时输出 `[]`，`--type` 缺失值或去空白后为空按参数错误处理（退出码 2）。
- 查询结果记录只含 `path`、`type`、`tags`，不区分命中方式、不含内部编号；源文件事后被删除仍可按登记标签入选，仅在传入 `--check-files` 时为最终入选记录追加 `file_status`（`present`、`missing`、`not_file`），任一入选记录状态无法读取则整次查询失败，未入选素材不影响查询。
- `export` 不接受标签、类型等任何筛选参数，导出全部登记记录；结果按首次登记顺序排列，每条素材仅出现一次且只含 `path`、`type`、`tags`（无 `file_status` 或内部编号），保留规范绝对路径、类型文本与完整标签顺序。
- 导出直接反映数据库中的登记记录：不读取素材内容、不检查登记路径当前的文件状态，源文件事后被删除或原路径变成目录都不会漏掉素材；导出不改动数据库与素材文件。
- 已存在但损坏或不属于本产品结构的数据库会报错，不会被覆盖、补表或重建；读取失败时不输出部分记录。
- `add` 的参数缺失、类型/标签为空、路径不存在或不是普通文件、重复登记、把目录数据库自身登记为素材、数据库无法打开或写入时：退出码 2，标准输出为空，标准错误给出原因，不输出调用栈。
- 缺少 `--db`、数据库路径为空、子命令传入不支持的参数、数据库路径指向目录、父目录缺失、数据库无法打开或读取、内容损坏或表结构不兼容时：退出码 2，标准输出为空，标准错误给出原因，不输出调用栈。
